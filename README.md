## Supermarket Sales Data Analysis using Python

### Project Overview

This project is a exploratory data analysis project using a supermarket sales dataset from Kaggle. 

The main purpose of the project was to practise the fundamental steps involved in a real-world data analysis workflow, including understanding the dataset, checking data quality, preparing the data, analysing key variables, creating visualisations, and identifying useful business insights.

### What I Expected to Achieve

The main goals of this project were to:

* Build confidence in using Python for data analysis.
* Learn how to load and explore a CSV dataset using Pandas.
* Understand the structure, data types, and quality of a dataset.
* Check for missing values, duplicate records, and inconsistent categories.
* Perform exploratory data analysis on sales, customers, branches, products, payment methods, and time-based trends.
* Create clear visualisations using Matplotlib and Seaborn.
* Understand basic statistical relationships using correlation analysis.
* Translate analysis results into simple business insights.

### What I Achieved

Through this project, I successfully:

* Loaded and explored a dataset containing 1,000 supermarket transactions and 17 variables.
* Checked the dataset for missing values and duplicate records.
* Reviewed categorical variables for consistency.
* Identified a one-to-one relationship between branch and city values and documented a potential location-label inconsistency in the dataset.
* Converted date and time fields into more appropriate formats for analysis.
* Analysed total and average sales across branches, product lines, customer types, gender groups, and payment methods.
* Examined sales patterns by day of the week and month.
* Compared transaction counts with total and average sales to avoid misleading conclusions.
* Created bar charts, line charts, histograms, scatter plots, and a correlation heatmap.
* Used correlation analysis to explore relationships between numerical variables such as Unit Price, Quantity, Sales, Gross Income, and Rating.
* Developed a better understanding of how exploratory data analysis can support business decision-making.

### Project Outcome

This project helped me strengthen my foundation in Python-based data analysis and understand how to move from raw transactional data to structured analysis and meaningful business insights.
